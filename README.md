# George Washington: A Founder, A President

A responsive, single-page history project about George Washington's life, leadership, presidency, and complex legacy.

## Run locally

Open `index.html` in a web browser. The site uses plain HTML, CSS, and JavaScript.

## Publish with GitHub Pages

The workflow in `.github/workflows/pages.yml` publishes the site whenever changes are pushed to the `main` branch. In the repository's **Settings → Pages**, select **GitHub Actions** as the build and deployment source.
